# Example of MMDAgent-EX

This repository contains materials and sample files for MMDAgent-EX.

See https://mmdagent-ex.dev/

## Download

The CG avatars "Gene" (`gene/`) and "Uka" (`uka/`) are git submodules, so
GitHub's "Download ZIP" button does **not** include them. Get a complete copy
in one of these two ways:

- Download `example.zip` from the
  [latest release](https://github.com/mmdagent-ex/example/releases/latest)
  (direct link: <https://github.com/mmdagent-ex/example/releases/latest/download/example.zip>)
  and unzip it. No git needed.
- Or clone with submodules:

  ```shell
  git clone --recursive https://github.com/mmdagent-ex/example
  ```

Then start MMDAgent-EX with `example/main.mdf`.
